# Bảng duyệt luật (RULES-REVIEW-SHEET)

Mỗi dòng = 1 luật. Bạn đọc cột **Tình huống / Kết quả mong đợi**, tick **Đã duyệt** khi đúng. AI cập nhật bảng này sau **mỗi task engine**
(thêm dòng, đổi "Tên test" từ "(dự kiến)" thành tên thật). Nhãn: `[RULE]` luật chuẩn · `[DECISION]` bạn đã chốt · `[GUESS]` chưa chắc.
Tên test là chuỗi trong `it(...)` ở `packages/game-engine`; tìm bằng `pnpm --filter @yugi/game-engine test -t "<tên>"`.
